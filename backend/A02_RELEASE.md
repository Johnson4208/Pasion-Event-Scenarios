# A02 information clocks and fiscal periods

New common/time.py separates offset-aware information instants, InformationClocks (published/ingested/accepted with known_at=max), MarketSession (venue/IANA timezone/completion), and ForecastHorizon with explicit units. Finance period records in finance/periods.py separate AccountingPeriod and BalanceAsOf. Fiscal calendar validation and quarter starts use issuer-declared boundaries, never day counts or a calendar-year heuristic.

F03 admission now persists immutable information_clocks and period_context alongside existing canonical fields. indexed_at is the existing financial ingestion clock; accepted_at is actual review acceptance. Historical revisions remain append-only; loader uses eligible_at_origin. Existing legacy facts retain their stored known_at and are not backdated. Derived known_at is maximum actual input instant. Direct standalone quarters take precedence over compatible YTD differencing. Only additive FLOW definitions can be differenced or bridged; reported YTD EPS is never subtracted. EPS still uses common profit and weighted-average shares with definition/period/context gates.

Q from Q1/H1 and TTM from priorFY/currentYTD/priorYTD or four contiguous quarters stay deterministic. Missing bridge coverage produces INCOMPLETE_TTM unless a complete standalone-quarter alternative exists. FY-to-TTM and first-quarter YTD-to-Q identity conversions are now explicitly DERIVED with their input ID; synthetic IDs are regenerated after period context changes. Actual report IDs and reviewed source IDs remain unchanged. No fiscal dropdown/UI navigation was changed.

MarketSession and ForecastHorizon types are available contracts; existing provider/technical adapters already enforce their own completed-session gates and have not all been migrated to these constructors. No trading date is substituted for an accounting duration or local display clock. MarketSession permits a closing time on the following day for overnight venues; its venue opening date must match the declared session date. A completed bar requires origin at/after close and known_at at/before origin.

Fixtures cover Q1=100/H1=240 => Q2=140, standalone Q2 not resubtracted, missing prior TTM unavailable, non-calendar fiscal year, July ingestion absent from earlier origin, timezone ordering, horizon-unit declarations, bar completion, and existing revision/EPS/semantic tests. Historical research remains origin-bound; sources accepted later cannot enter an earlier forecast even if publication was earlier. Production source/calendar validation remains required.
