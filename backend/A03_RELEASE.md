# A03 governed report extraction and review

Extends F12 financial staging rather than generic document QA. New stages retain raw_observations separate from proposed numeric interpretations: source text/cell, page/section/row/column, available bounding box, original document hash/parser, candidate metric, correction rationale and proposed scale/value. Originals remain unchanged. Corrections create child stages through optional parent_id; accepted decisions cannot be edited. UI includes correction-parent ID and AMBIGUOUS disposition alongside ACCEPT/REJECT. An ambiguous decision is terminal for that stage and publishes no facts; resolution requires a new reviewed stage.

Financial context fingerprint includes issuer, definition, duration/basis, unit, currency, accounting standard, perimeter, ownership, restatement and revision. Duplicate context in a stage is rejected; acceptance refuses already-accepted context/revision keys rather than rewriting history. Ownership is preserved into canonical facts and compared in ratio compatibility when present. Legacy facts retain their existing unspecified ownership; a known ownership is not silently matched to an unknown one.

Optional structured_context sidecars validate namespace/concept/context_ref/unit_ref/entity identifier/decimals/dimensions/filing/amendment/source locator against reviewed period and currency. This is an adapter admission contract, not an installed XBRL/iXBRL parser. Arelle is neither installed nor claimed verified. External adapters still require original-document coordinates, explicit accounting mapping and the same human review. No VAS/IFRS/US-GAAP country column positions are assumed. D&A eligibility remains an explicit reviewed statement, never inferred from its presence in a cash-flow note or OCR confidence.

Staging jobs are immutable finance_stages linked to document_service document IDs; decisions, accepted IDs and rejected/ambiguous states retain reviewer/timestamps in admin history. Generic extraction/retry/download/search/optional QA routes remain intact. Accounting identities only issue warnings, with no OCR self-repair. Accepted public citations expose bounded reviewed excerpts, not whole admin originals. Existing F12 original-document deletion retention remains in force.

Validation fixtures preserve original 100 after proposed/accepted 110 correction, withhold ambiguous contexts, use an explicitly reversed IFRS table, keep cash-flow D&A ineligible and reject structured period mismatches. Existing finance period/ratio fixtures remain required. No real filing or country taxonomy adapter was accepted or certified.

Focused F01/F03 browser checks verify role protection and source drawers; no dedicated end-to-end admin mapping test was added in this release. Full backend suite was not rerun for A03. App restarted with A03 active; real XBRL parser/adapters remain uninstalled and unverified.
