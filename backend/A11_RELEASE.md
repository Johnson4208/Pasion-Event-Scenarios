Retains Phase A authenticated manual lots/cash/as_of/import status. Unrealized P&L requires valid lot costs and marks; foreign historical cost basis remains unavailable without acquisition FX. Manual cash after entered reserves is separate context, not executable buying power.

Adds private immutable manual transaction archive via POST /api/portfolio/transactions. Confirm opening manual account first; submit stable request_id, type (BUY/SELL/DEPOSIT/WITHDRAWAL/DIVIDEND/SPLIT/FEE/TAX/FX/CORRECTION), occurred_at, currency, amount, optional ticker/quantity/fees/taxes, source_note. Trade/split entries require positive quantity and ticker; future clocks rejected. Stable retry returns the same event; changed retry payload fails. Owner is session-derived. Entries are MANUAL_UNRECONCILED, not broker fills. They do not silently mutate confirmed cash/holdings; any existing trading baseline is invalidated pending reconciliation. Observation edits remain separate MANUAL_SNAPSHOT events. Phase B automatic transaction replay, corporate-action/FX-lot reconciliation and actual realized cost-basis engine remain unfinished and gated.

Risk contributions sum to daily volatility; missing marks/FX/return coverage withhold rather than dropping assets. These are risk diagnostics, not actual performance.
