# A12 vintage-safe macro and exposure stress

Extends F09 immutable series/revision store. Each newly admitted observation now retains previous_vintage_id for the same series/period; source frequency, local release clock, observed period/value, known_at and expiry remain explicit. Origin reads exclude later accepted/released revisions, retain old immutable observations and never backfill a source into earlier forecast origins.

Commodity stress retains per-issuer/segment output/input volumes, grade/location/unit, contract reset, effective repricing fractions, inventory lag, hedge scope and accepted issuer source facts. It now identifies economic role, source IDs, explicit component semantics and a proposed EBIT-driver delta with period/currency. Output/input price shocks are user assumptions; physical mapping is admin-reviewed; pass-through/hedge/incremental cost assumptions are in the exposure's currency. No uniform producer benefit or sector inference.

Cross-currency API price shocks require fx_series_id. Series must be a reviewed FX vintage, known/fresh at origin with unit exactly exposureCurrency/shockCurrency. Effective output/input price deltas are multiplied by that rate; pass-through/hedge/cost totals stay in exposure currency. Reversed, missing or stale conversion blocks stress. FX evidence returns source URL, series/vintage IDs, rate and known clock. Native Company Research form still uses same-currency shocks; cross-currency input is currently a typed API/sidecar workflow, not a new UI selector.

market/macro_research.py adds offline fixed-penalty ridge comparison of market/sector baseline vs one-lag commodity shock. Training normalization uses past-only training data; labels must be mature before held-out cutoff, feature known_at<=origin, chronological origins, explicit business-EBIT vs stock-return target and source IDs. Reports a single later holdout MSE/skill, never live prediction or causal conclusion. This helper is not a registered/deployed issuer model or a rolling multi-cohort production validation service. No real point-in-time training dataset supplied.

Minimum-variance hedge helper computes covariance(exposure,hedge)/variance(hedge) for at least 60 aligned supplied changes, returning RESEARCH_ONLY and quantity null. Caller must establish source/date alignment; no contract size, margin, basis-risk, costs, liquidity or validated hedge routing exists. No broker operation or derivative sizing is enabled.

Stress preserves the base case: UNVERIFIED_SCENARIO_NOT_BASELINE_UPDATE proposal requires a separate F04/A06 driver review before valuation. Missing predictive model is explicitly UNAVAILABLE, hedging remains research-only. Existing MacroRegime country scope/coverage and Company Research stress UI retained. No stock-market forecast is manufactured from business stress results.

Validation: all 8 existing macro/API tests and 18 A12 tests (including inherited vintage/stress fixtures) passed. Both F09 browser checks passed. No frontend code changed, so the previous production build remains applicable. Final source-ID/role response fields are additive metadata. Full backend suite was not repeated; offline research helpers do not establish real economic/model validity. Local project restarted for A12 activation.
