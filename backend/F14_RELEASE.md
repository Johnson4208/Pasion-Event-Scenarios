# F14 reviewed analytic assistant

The main Assistant view uses authenticated POST `/api/research/assistant` with strict read-only tools `metric`, `evidence`, `assumptions`. Required fields are question and issuer ticker; period is Q/YTD/FY/TTM, optional metric/end/origin. Metric names are registered canonical IDs or a small question alias registry. Ambiguous questions request explicit selection; missing, incompatible or uncited values are withheld. Exact decimal strings come from F03, with no arithmetic in prose. Accepted source IDs and reviewed excerpts open inline and link into Investment Research. Source metadata omits admin original documents and reviewer/account secrets.

Assumptions tool loads only the session owner's F04 scenario (base/upside/downside), returning whitelisted economic fields and verified/unverified status. It does not generate a fair value. No account cash, fact, forecast, model or Distribution mutation tool exists. No administrative retrieval is provided, even when the caller is an admin. Source excerpts are treated only as untrusted display data. No LLM call is made; deterministic explanations are the current thin presentation fallback. Future model prose requires numeric/citation validation and cannot gain write tools. Generic admin document AI remains separate.

Per-account rate limit is 20 requests/minute, protected by a lock; local in-memory limits reset on process restart. Distributed rate limiting remains a production deployment concern. Questions max 500 characters; typed payload size limited to 10KB. Sources are limited to 20 accepted IDs per answer. Question alias coverage is deliberately narrow; selected ticker/period are explicit, no inferred financial assumptions. Existing sample dashboard helper responses remain labeled as sample; the main Assistant is reviewed context.

Validation: 3 core tests cover missing values, write-tool rejection, numeric string fidelity, injection text isolation, ambiguous metrics and rate limiting. Focused browser missing-data check passed; production build passed with existing bundle warning. No real economic sources or generative provider were certified.
