# F15 admin shadow Distribution

Added only to Administration. No user tab, recommendations, routing, cash/holdings reservation, allocation shares or broker execution. All candidate allocation_quantity fields are null. Status is WITHHELD when gates fail, REVIEW_ONLY after admission review, always with OUT_OF_TIME_VALIDATION_AND_OPERATIONAL_RELEASE_REQUIRED.

Admin GET /api/admin/distribution returns isolated pools/candidates/events. POST /api/admin/distribution/pools registers immutable reviewed simulated-slot capacity with horizon, utility_definition, utility_version, policy and expires_at. POST /api/admin/distribution/candidates takes owner, pool_id, accepted fact_id, typed F07 draft, matching horizon/utility fields, review_note and explicit suitability_reviewed/name_sector_reviewed/tape_window_reviewed flags. These are manual operator assertions; there is no independently verified tape/utility registry or automated suitability engine. Shared F07 feasibility reads reviewed account/quote state; accepted F03 issuer fact is required. Numeric utility ranking remains unavailable.

POST /api/admin/distribution/transitions takes candidate_id, pool_id, stable idempotency_key and RESERVE_SHADOW_SLOT/RELEASE_SHADOW_SLOT. SQLite BEGIN IMMEDIATE serializes read/check/write. Unique retry keys return original transitions; mismatched key reuse fails. Candidate lifecycle allows one reserve and one release only. Account/quote versions and expiry are rechecked on reservation. Simulated slots never represent shares, cash or actual sellable holdings. Capacity state sums active reservations for reconciliation.

Real crowding/exposure/cash reservation, utility ranking, candidate diversity and operational allocation remain withheld pending validated policies, verified tape and out-of-time validation. No financial facts/valuation changed to promote variety. Server roles protect all routes. Internal owner identity and capacity never appear in member research APIs. General F01 audit records action/status, while immutable shadow events preserve timestamps. Production identity/storage review remains required.

Validation: 3 focused backend/API tests passed, including four concurrent identical retries producing one reservation, bounded capacity, single-shot release, failed gates withholding quantities and member denial. Both focused F01/F15 browser checks passed. Production build passed with the existing bundle warning. No real capacity or utility dataset was supplied or certified.
