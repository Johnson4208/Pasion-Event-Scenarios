# PASION Event Scenarios — frontend preview

This is a standalone static design preview. It contains only HTML, CSS, and browser-side JavaScript. It has no backend, account integration, API calls, source collection, or live financial data.

All displayed scenario percentages are illustrative mock values. The three sample outcomes sum to 100% by construction. Filters, horizon controls, the preview button, reset control, clipboard summary, responsive sidebar, and informational dialogs work locally in the browser.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No install step is needed.

## GitHub Pages

The repository workflow publishes only this folder. The rest of the PASION repository is not included in the Pages artifact.
