# Original PASION frontend demo

Uses the original React components, styles, fonts and images. `npm install`, then `npm run dev:frontend`; production build: `npm run build`.

Live preview: https://johnson4208.github.io/Pasion-Event-Scenarios-Frontend-Demo/

Use demo@example.com and any sample password. No credentials are stored or transmitted by the demo transport. Company, portfolio, valuation, comparison and event values are illustrative. Live evidence, execution and backend-only actions are not connected.
